# AI 学习笔记（示例，供知识库问答演示）

## 一、什么是 RAG
RAG 全称 Retrieval-Augmented Generation，检索增强生成。
核心思路：大模型不知道你私有资料的内容，所以先"检索"再"生成"。
流程：把文档切分成小块 -> 用向量模型转成向量存入向量数据库 -> 提问时把问题也转成向量，
检索最相关的片段 -> 把片段连同出处交给大模型，让它只依据片段回答，避免编造（幻觉）。

## 二、什么是 Agent 和 Function Calling
Agent（智能体）= 大模型负责决策 + 工具负责真实执行 + 循环直到完成任务。
Function Calling（函数调用）：把工具写成 JSON Schema 说明书发给模型，
模型不直接执行代码，而是返回"调用哪个工具、传什么参数"，由本地 Python 真正执行，再把结果回传。

## 三、LangGraph 状态机
LangGraph 把 Agent 画成图：节点（agent 决策 / tools 执行）+ 边（条件路由）。
模型还想调工具就去 tools，不需要了就结束，消息用 add_messages 自动累积。

## 四、多模态：视觉桥
文本模型"看不见"图片。视觉桥方案：给文本模型加一个 analyze_image 工具，
内部调用免费视觉模型（如 GLM-4V / Qwen-VL）把图片转成文字描述，再回传给主模型。
